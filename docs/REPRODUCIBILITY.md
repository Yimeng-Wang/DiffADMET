# Reproduction scope and maintenance notes

This release contains the main training source and a separately prepared real graph/label BIN package without plaintext SMILES. Original CSVs, private ID mapping, trained weights and service code are excluded. The processed graph-to-label pairs are publicly releasable with the owner's explicit authorization; no confidentiality guarantee is made.

Training/evaluation can start directly from the supplied cached graphs, original labels/masks, fixed splits, task relationships and fold normalization. Original SMILES-to-conformer preprocessing cannot independently be repeated. No complete historical paper-score or website-checkpoint equivalence is claimed without the actual study training version and full validation.

## Preserved active configuration

- 135 endpoints, fixed task order, classification mask+BCE and regression mask+Huber losses.
- AttentiveFP graph encoders, 128-dimensional graph features, two GNN layers, two readout steps, dropout 0.3, 256-dimensional shared predictor feature and 128-dimensional task feature.
- `fusion_type='2dg'`, task-modality attention enabled, matrix relations and directed transfer enabled. Cross-attention, alignment, and adversarial losses disabled by the entry point. Only this fixed active path is retained; inactive modules and mode switches were removed.
- Classification objective: classification + 0.1 × regression, Huber delta 1, AdamW learning rate 0.0003; regression objective: 0.25 × classification + regression, Huber delta 1.5, learning rate 0.0006. Difficulty arrays, schedules, regression boost factors, weight decay 0.0001, and gradient clipping 5 are retained.
- ReduceLROnPlateau uses validation monitor, factor 0.7, patience 12, minimum learning rate 0.00001. Classification early stopping patience 50; regression patience 40.
- Regression early stopping and exported legacy `R2` fields compute Pearson correlation squared. They must not be presented as coefficient-of-determination R-squared.

## Repairs and portability changes

1. The supplied training entries passed `transfer_gate=3` while their adjacent model constructor did not accept that parameter. The release adds the existing website implementation: a learnable `transfer_rate`, `gamma = sigmoid(transfer_rate)`, and interpolation between original and transferred task features. `sigmoid(3)` is approximately 0.953. This is an interface repair based on existing project code, not proof of historical checkpoint provenance. Only this gate mechanism is taken from the website source. The website source also uses softplus with row-normalized matrix weights and reuses fusion-branch graph encoders for task-modality attention; the supplied training source uses column normalization and separate encoder modules. Those training-source behaviors remain in this release. Exact equivalence to a previously trained model has not been established.
2. Removed commented historical experiments, long repetitive documentation, unused top-level functions, unused feature families, single-task/fine-tuning/distributed methods, unused imports and learner state. Existing third-party copyright/attribution notices remain. `cleanup_manifest.json` records the initial retained core files and removed definitions.
3. Training entries are consolidated into guarded `src/train.py`. The original classification entry selected folds `[0,2,3,4]`; the public default runs all five and `--folds 0 2 3 4` can select that original subset. The original regression entry selected all five. The seed is set once before the selected folds, following the original sequential-run behavior; selecting a subset can change later initialization sequences.
4. CSV mode retains user-data rows and generates graphs. The real BIN release instead follows the supplied legacy dataset rule: keep the first record for each exact SMILES within each original split, and preserve the last valid provided cached graph occurrence. Real labels/masks and original fixed splits are exported with anonymous IDs; cached geometry is not regenerated. Original fold normalization is provided as JSON and is the default in BIN mode. Counts, overlaps and normalization comparisons are in the data manifest.
5. The optional user-owned CSV/demo RDKit conformer generation specifies seed 66; the original call had no explicit conformer seed. It retains 10 conformers, MMFF optimization, lowest-energy selection, and 2D coordinate fallback. This improves repeatability but may change geometry and outputs relative to historical caches. PyTorch/DGL seeds are also set; identical results across devices/library versions are not guaranteed.
6. Added a zero-valued edge-feature tensor of shape `(number_of_edges, 1)` for 3D graphs with no angles/edges, so single-atom or simple molecules batch consistently. Feature dimensions remain 78/13 for 2D graphs and 4/1 for 3D graphs.
7. Sparse regression metrics retain a NaN slot for endpoints with insufficient labels instead of shortening the task list and shifting endpoint-to-metric assignments. Train/validation monitoring uses the mean over defined endpoint metrics; completely undefined validation monitors fail explicitly.
8. Only classification `_evalue_c.csv` or original-label-scale regression `_evalue_r_denorm.csv` tables are saved for each available split. Each fold also retains `best.pth`, `normalizer.json`, `run_manifest.json` and `history.json`. Early stopping writes and reloads the retained best checkpoint. Per-record prediction/probability/label/mask CSVs are omitted. Run artifacts remain outside publication archives. The builder uses an explicit source allowlist and a separate approved real-data inventory. Original CSVs, private mappings, legacy pickle containers, pretrained weights and local outputs are never bundled.

## Independent validation

See `VALIDATION.md` for checks actually executed for this release. The smoke data contain artificial labels and an identity relation matrix, so they verify executability, not biological performance. No split-generation helper is distributed. Both BIN and CSV modes read existing fold assignments; they do not run K-fold splitting. The real five-fold data were independently rechecked against all ten original training/validation CSVs: membership, row order, labels and masks match exactly. The real BIN release preserves the provided original split assignments and relation matrix; its historical matrix selection rule is not reconstructed.

Project-authored code has no selected repository-wide license. Third-party licensing and attributions are documented in `NOTICE.md`.


### Molecule overlap versus endpoint-observation overlap

The supplied folds share exact-source molecule identities between training, validation and test. An independent check of **all five folds** found zero shared observed `(molecule_id, endpoint)` pairs between any two of those sets: shared molecules have measurements at different endpoints. This is a distinction between molecule-disjoint evaluation and endpoint-observation holdout; it is not a claim that entirely unseen-molecule generalization has been established. The identity check follows the original exact SMILES keys and does not audit all canonical aliases. Both molecule counts and endpoint-observation counts are preserved in the manifest. The external set shares no such molecule IDs with any fold's training set.

## Fixed-path cleanup

The public model forward signature is `forward(self, graph_data)` and returns a `(batch, 135)` logits tensor. It has no call-time architecture switches. The former fixed settings (`cross_attention=False`, `fusion_type='2dg'`, alignment disabled, task modality and directed transfer enabled, adversarial disabled) are implemented directly. The constructor no longer accepts alternative relationship modes, embedding dimension, discriminator hidden dimension, task-type discriminator labels, or a transfer-gate option. Matrix transfer keeps the original column normalization; the learnable gate starts at3. The task-attention branch still receives both 2D and 3D graphs, and retains its independent encoders. The fusion branch retains the active 2D encoder and removes its unused 3D encoder.

Original epoch/batch/optimizer/early-stop values remain, and the seed is fixed66. The normalizer supplied for each preset fold remains the BIN default. Removing unused modules changes initialization and dropout RNG consumption even with the same seed. Shared-weight forward/gradient/loss/metric equivalence checks test the effective mathematical path; they do not prove identical initial weights, training trajectories or full paper scores after cleanup.
